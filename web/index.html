    What is a packed PNG?

    A packed PNG is an ordinary, viewable photograph with one extra ancillary chunk — dePH or dEPt, matched case-insensitively — holding the depth map. The colour image stays readable in any PNG viewer; this page reads the chunk and displaces the photograph with it.

    The payload is either:

    • a complete grayscale PNG, self-describing and returned byte-for-byte; or
    • exactly width × height bytes of raw 8-bit grey, taking its dimensions from the file's own IHDR.

    A file is one of three things here, and the distinction is deliberate: a relief (a depth map was read), a photo (a readable image with no depth), or unreadable. A file that is still being read, or whose depth chunk is malformed, is never shown as “no depth” — a half-read file has not answered yet.

    A depth map whose dimensions disagree with the photo is refused rather than stretched: a pair that does not line up cannot be made correct by scaling it.

    Saving one: a relief can be written back out as a packed PNG from the viewer — the colour image's own bytes with a single dePH chunk, placed before the image data. A photo has no depth map to pack and a .splat is not a PNG, so neither offers the action; the viewer says which.
